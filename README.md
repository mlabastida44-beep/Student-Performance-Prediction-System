# Student Performance Prediction System

A classroom prototype that flags students who may be at risk of failing the final Mathematics grade.

## Problem
Academic risk is often noticed only after poor results. This prototype explores early identification using available student indicators (study time, absences, past failures, G1, G2, and others).

## Dataset
UCI Machine Learning Repository, *Student Performance* (ID 320): https://archive.ics.uci.edu/dataset/320/student+performance
The Mathematics file (`student-mat.csv`, 395 records) is used.

## Prediction target
`G3 < 10` = **AT RISK**; `G3 >= 10` = **NOT AT RISK**.
`G3` is the target only and is never used as an input feature.

## Technologies
Python 3.10+, pandas, scikit-learn (Random Forest), joblib, Streamlit, GitHub.

## Installation and run
```bash
pip install -r requirements.txt
python train_model.py      # downloads data, trains model, creates student_data.csv, student_model.pkl, evaluation_results.txt
streamlit run app.py       # opens http://localhost:8501
```
In the app, download the sample input CSV, upload it, review predictions, and download the results.

## Evaluation
See `evaluation_results.txt` (generated by `train_model.py`): accuracy, precision, recall and F1-score per class.

## Limitations and responsible use
- Trained on one Portuguese secondary-school dataset; it may not generalize to other institutions or populations.
- G1 and G2 are strong predictors, so predictions come late in the term.
- Predictions are not diagnoses and must not be the sole basis for real student decisions.
